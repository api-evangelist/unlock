# Unlock (Unlock Technologies, Inc.)

> Unlock Technologies is a Tempe, Arizona fintech founded in 2020. Its product is the home equity
> agreement (HEA): a homeowner takes $15,000-$500,000 in cash today in exchange for a share of the
> home's future value, with no monthly payments and no interest, settled on sale, refinance, or at
> the end of the ten-year term. It is licensed in 26 US states.

> Provenance: this file was GENERATED by API Evangelist on 2026-09-02 from probes of Unlock's own
> public surface. Unlock does not publish an llms.txt — https://www.unlock.com/llms.txt returns 404.
> This is a third-party profile, not a provider document.

## What Unlock does NOT publish

Unlock has no developer program. There is no developer portal, no API reference, no SDK, no CLI, no
Postman collection, no sandbox, no API key issuance, no partner API, no MCP server, no A2A agent
card, no llms.txt, no security.txt, no status page and no changelog. api.unlock.com,
developer.unlock.com, docs.unlock.com and mcp.unlock.com do not resolve. Every /.well-known/ path
was probed on all four Unlock hosts and none returned a document.

## What Unlock DOES expose

Two anonymously readable REST surfaces on www.unlock.com, both read-only without credentials, both
undocumented by Unlock. They were discovered from the WordPress REST route index at
https://www.unlock.com/wp-json/, which publishes a full argument schema for every route — that index
is what made the OpenAPI documents in this profile derivable without guessing.

### Unlock Site Content API — https://www.unlock.com/wp-json/unlock/v1
Unlock's OWN namespaces (`unlock/v1`, `unlock/v2`, `unlk/v1`), custom-registered rather than
WordPress core. 22 GET operations.
- `/unlock/v1/active-states` — the 26 states where the HEA is offered, plus a count. Authoritative.
- `/unlock/v1/company` — corporate blurb and the Tempe headquarters address.
- `/unlock/v1/faq` and `/unlock/v1/faq_categories` — 145 HEA questions and answers, categorised.
- `/unlock/v1/testimonials` — 8 published homeowner testimonials.
- `/unlock/v1/education`, `/education/lessons`, `/education/topics` — the Unlock Learn curriculum.
- `/unlock/v1/disclaimer` and `/unlock/v2/disclosures` — legal text. Disclosures returns HTML, not JSON.
- `/unlock/v1/social`, `/unlock/v1/logos`, `/unlock/v1/menus/{location}` — brand and navigation.
- `/unlk/v1/education/restore` and `/education/save` — per-learner progress, keyed on an email address.

### Unlock Editorial API — https://www.unlock.com/wp-json/wp/v2
WordPress core content namespace. 30 GET operations profiled. At capture: 251 blog posts, 24 pages,
778 media items, 9 Learn articles, 13 homeowner stories, 6 topics, 1 lesson, 11 authors.
- `/wp/v2/search` — cross-type search, the right first call.
- `/wp/v2/posts`, `/wp/v2/articles`, `/wp/v2/stories`, `/wp/v2/lessons`, `/wp/v2/topics`, `/wp/v2/authors`
- `/wp/v2/categories`, `/wp/v2/education_category` — taxonomies. `/wp/v2/tags` is registered but EMPTY.
- `/wp/v2/types`, `/wp/v2/taxonomies`, `/wp/v2/statuses` — self-describing metadata.

## How to call it

- No authentication for reads. Anonymous responses carry `Allow: GET`.
- Pagination: `page`, `per_page` (1-100), `offset`. Totals in `X-WP-Total` / `X-WP-TotalPages`;
  next page in the `Link` header, `rel="next"`.
- `context=view` or `context=embed` only. `context=edit` returns 401 `rest_forbidden_context`.
- Errors are the WordPress envelope (`code`, `message`, `data.status`) as application/json — NOT
  RFC 9457 problem+json. Codes observed: `rest_no_route` 404, `rest_post_invalid_id` 404,
  `rest_invalid_param` 400, `rest_missing_callback_param` 400, `rest_forbidden_context` 401.
- No rate-limit headers are returned and no limits are published. The edge serves
  `Cache-Control: public, max-age=604800`.
- Writes exist in the route index but require a WordPress application password, which Unlock does
  not issue to the public. Treat this surface as read-only.
